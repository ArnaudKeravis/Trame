# Trame OS

Espace réservé aux outils internes qui encodent la méthode Trame.

## Statut

**Non exposé aux clients.** Les clients achètent les résultats, pas les agents.

## Vision

24 agents organisés autour de la méthode :

- Accélérateur de delivery
- Showcase vivant en rendez-vous
- Base des futurs accélérateurs packagés

## Structure prévue

```
trame-os/
├── agents/           # Définitions d'agents par phase méthode
├── playbooks/        # Patterns extraits des missions
├── prompts/          # Templates internes
└── evals/            # Métriques qualité delivery
```

## Règle

Chaque mission doit produire un asset réutilisable vers les playbooks.
