# Benchmark marché

Source : session de cadrage Trame 2026.

## Paysage concurrentiel

### Géants stratégie (McKinsey, BCG X, Deloitte)

- **Offre** : stratégie + build + scale, bout en bout
- **Prix** : 500–700 $/h, projets 9–24 mois
- **Limite** : trop cher et lent pour le mid-market

### Firmes de design (IDEO, frog, Fjord)

- **Offre** : codesign, expérience, design thinking
- **Prix** : tickets entreprise
- **Limite** : expérience client, pas workflows internes ; souvent absorbées par de plus gros groupes

### Boutiques automatisation (Neurons Lab, etc.)

- **Offre** : systèmes qui tournent, vite
- **Prix** : 5–50 k$, 30–60 jours
- **Limite** : transactionnel, pas de codesign, builders purs

### Change management (Prosci/ADKAR)

- **Offre** : adoption, conduite du changement
- **Durée** : 6–18 mois
- **Limite** : pas de build ni profondeur IA

### Solos / SMB shippers

- **Offre** : automatisation pattern-matchée
- **Limite** : générique, dépendant du fondateur
