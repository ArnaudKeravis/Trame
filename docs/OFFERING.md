# Offre Trame — détail commercial

## Vue d'ensemble

Quatre étages — chacun vend le suivant.

```
Discovery ──► Sprint ──► Operating Partner ──► Accélérateurs
  3-6k€      12-20k€      3-6k€/mois         licence
```

---

## 1. Discovery & cadrage

| | |
|---|---|
| **Durée** | 1 semaine |
| **Objectif** | Observer le travail réel, cibler le workflow le plus douloureux |
| **Livrables** | Cartographie du workflow actuel, douleur chiffrée, recommandation de pilote |
| **Prix** | 3–6 k€ |

**Pour qui** : équipes qui sentent la douleur mais ne savent pas par où commencer.

---

## 2. Workflow Transformation Sprint ⭐

| | |
|---|---|
| **Durée** | 2–3 semaines |
| **Objectif** | Codesign + pilote-preuve fail-fast — **l'unité de preuve** |
| **Livrables** | Workflow cible co-conçu, pilote fonctionnel, métriques avant/après, plan de transfert |
| **Prix** | 12–20 k€ |

**Cœur de l'offre de lancement.** Prix de départ à trancher (lancement vs cible).

### Workflows pilotes prioritaires

1. **Appels d'offres / pitchs** — cas d'usage interne Trame
2. **Reporting de campagnes** — ROI marketing limpide
3. Analyse de verbatims, veille, préparation de décisions

---

## 3. Operating Partner

| | |
|---|---|
| **Format** | Abonnement mensuel |
| **Objectif** | Copilote IA des équipes — nouveaux workflows, adoption, mesure |
| **Prix** | 3–6 k€/mois |

**Cible récurrence** : 3 retainers à 4 k€ = 144 k€/an de base.

---

## 4. Accélérateurs

| | |
|---|---|
| **Format** | Licence produit |
| **Contenu** | Patterns & playbooks réutilisables extraits des missions |
| **Déclencheur** | Même workflow douloureux observé chez 8–10 clients |

Revenu hors temps passé — évolution naturelle du moat.

---

## Ce que nous ne vendons pas

- Industrialisation à grande échelle (autre métier)
- Intégration technique lourde
- Licences d'agents ou de Trame OS
- Synthèse de réunions générique (commoditisé)

---

## Message commercial type

> « Vous perdez 3 jours par appel d'offres ? En 3 semaines, on co-conçoit un workflow qui ramène ça à une demi-journée — avec vos équipes, pas contre elles. Preuve chiffrée, puis on vous passe la main. »
