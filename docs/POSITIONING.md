# Positionnement Trame

## Statement

**Cabinet de transformation des workflows cognitifs** — conseil × production, mid-market, preuve rapide.

## Carte concurrentielle

```
                    ↑ Codesign
                    │
    Firmes design   │   Géants ($$$)
    (IDEO, frog)    │   (McKinsey, BCG X)
                    │
Transactionnel ─────┼───── Cognitif / connaissance
                    │
    Boutiques       │      TRAME
    automatisation  │   (espace ouvert)
    Change mgmt     │
                    ↓ Build
```

**Lecture** : codesign + cognitif existe chez les géants (chers) ou les firmes de design (absorbées). Les builders restent transactionnels. Le quadrant **cognitif × codesign au niveau mid-market est vide**.

## Archétypes du marché

| Archétype | Ce qu'ils vendent | Prix / rythme | Angle mort |
|-----------|-------------------|---------------|------------|
| Géants stratégie | Stratégie + build + scale | 500–700 $/h · 9–24 mois | Trop cher/lent · Fortune 500 |
| Firmes de design | Codesign, expérience | Tickets entreprise | Expérience client, pas workflows internes |
| Boutiques automatisation | Systèmes qui tournent | 5–50 k$ · 30–60 j | Transactionnel · pas de codesign |
| Change management | Adoption | 6–18 mois | Pas de build ni profondeur IA |
| Solos / SMB shippers | Automatisation pattern-matchée | Bas | Générique · dépendant du fondateur |

**Personne, en indépendant, ne combine** codesign + travail cognitif interne + preuve cheap pour le mid-market.

## Trois implications stratégiques

1. **Ne jamais se battre sur la tech ou la prod** — terrain des builders et intégrateurs
2. **Vendre du de-risking, pas un projet IA** — l'ennemi c'est le statu quo et le POC-jouet (échec à 40 %)
3. **Le pilote cheap est le cheval de Troie** — preuve en 2–3 sem. à faible coût vs 500 k€ / 12 mois chez les géants
