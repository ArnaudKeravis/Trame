# Trame

> **Révéler la trame du travail. La reconcevoir avec l'IA.**

Cabinet de transformation des **workflows cognitifs** — codesign, preuve rapide, transfert aux équipes.

---

## Vision

Nous ne vendons pas de l'IA. Nous vendons ses effets : temps gagné, charge cognitive réduite, adoption réussie.

Le positionnement : **par problème** (workflows cognitifs), pas par secteur. Preuve cheap en 2–3 semaines. Transfert, pas dépendance.

→ Vision complète : [`docs/PRODUCT_VISION.md`](./docs/PRODUCT_VISION.md)
